# survML: Tools for Flexible Survival Analysis Using Machine Learning

Statistical tools for analyzing time-to-event data using machine
learning. Implements survival stacking for conditional survival
estimation, standardized survival function estimation for current status
data, and methods for algorithm-agnostic variable importance.
